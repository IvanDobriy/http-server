# Описание
В данном проекте представлен пример реализации web-сервера с поддержкой спецификации servlet

# Сборка
Для сборки приложения необходимо выполнить команду : ./gradlew distTar
После исполнения команды сборка окажется в папке ./build/distributions

# Развертывание и запуск

- необходимо разархивировать tar архив
- зайти в папку bin
- для *nix систем выполнить запуск *.sh скрипта
- для windows выполнить запуск *.bat скрипта

Системные переменные: 
- http_server_container_path - путь до директории, в которой будут развернуты контейнеры

Если данный путь не указан, то директория с контейнерами будет автоматически создана в месте запуска приложения.

Пример запуска: 

JAVA_OPTS='-Xms1g -Xmx4g'  http_server_container_path='../' ./http-server 

Если нужно поменять конфигурацию логирования, то необходимо добавить свойство: '-Dlogging.config', например:

JAVA_OPTS='-Xms1g -Xmx4g -Dlogging.config=/path/to/log4j2.xml'  http_server_container_path='../' ./http-server 

Развертывание приложений:

- запустите сервер
- копируйте war архив приложения в папку containers

Архив должен автоматически разархивироваться, а приложение запуститься на текущем web-сервере.
